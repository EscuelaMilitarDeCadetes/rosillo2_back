# Plataforma Rosillo

Sistema de gestión de investigación institucional desarrollado en Django y React.

Permite administrar:

- Convocatorias de investigación
- Proyectos de investigación formal
- Investigación formativa (tesis de grado)
- Gestión documental
- Firma digital de documentos
- Seguimiento y evaluación

## Arquitectura general

Backend: Django + Django REST Framework  
Frontend: React  
Base de datos: PostgreSQL  
Servidor de archivos: almacenamiento en disco
