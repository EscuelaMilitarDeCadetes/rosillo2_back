# Plataforma Rosillo

Este es el backend del Sistema de Gestión de Investigación (SGI) de la Escuela Militar de Cadetes General José María Córdova, desarrollado con Django y Django REST Framework. Sirve como el motor y repositorio para la gestión de investigación formal, formativa de los procesos desarrollados dentro de esta institución de educación superior. Esta plataforma se desarrolla como parte e un proceso de mejora de la metodologia usada actualmente dentro de la intitución, el proyecto el cual derivó esta plataforma tiene por nombre: Plataforma para el seguimiento de la actividad investigativa de la Escuela Militar de Cadetes General José María Córdova
